Uncertainty-aware modeling · synthetic · non-clinical

Mindstate Signal Lab

A responsible-modeling lab about ambiguous synthetic self-reflection patterns, visible uncertainty, and the decision to abstain rather than force a confident classification.

Safety boundary: this is not a mental-health detector, screener, diagnosis system, treatment tool, crisis tool, or medical device. It uses synthetic non-clinical labels.

01 · Problem

How should a model behave when human-centered inputs are ambiguous?

The project does not ask a clinical question. It asks whether a synthetic workflow can classify broad non-clinical patterns while refusing low-confidence outputs and limiting user-facing actions to low-stakes reflection, follow-up questions, abstention, or human review.

02 · Data and provenance

One row represents a synthetic user-day.

Inputs include sleep, energy, stress, focus, activity, social interaction, journaling sentiment, screen time, workload, day of week, and missingness patterns. The generator includes latent strain and recovery fields for audit, but those fields are excluded from model features.

The synthetic design intentionally includes missingness, ambiguity, repeated users, and temporal order so the workflow can be tested against the problems it claims to address.

03 · Temporal feature boundary

Later observations must not rewrite earlier user-days.

The modernization review found that the earlier feature path used backward fill within user timelines before splitting. That allowed a later value to populate an earlier missing row and weakened temporal evaluation.

The corrected pipeline uses only causal forward fill, leaves unresolved missing values for training-fitted preprocessing, and includes regression tests proving that changing a future user-day cannot alter earlier engineered features.

04 · Evaluation design

Repeated users and time order are reviewed explicitly.

The project compares random-row, grouped-user, and temporal day-order proxy splits. It also exports class diagnostics, slice metrics, error examples, calibration summaries, and a transparent heuristic baseline.

The corrected causal feature path completed clean CI regeneration. The temporal proxy remains a local synthetic check rather than prospective real-world validation.

05 · Uncertainty and abstention

Coverage is part of the result.

The current wrapper retains about 21.8% of test rows and reaches about 71.2% accuracy on those retained rows; equivalently, it abstains on about 78.2% of rows. A high retained accuracy with low coverage is not equivalent to a generally useful classifier, and retained-set class balance must also be reviewed.

The threshold is an experimental project choice, not a clinically validated cutoff. Threshold selection and probability calibration remain explicit limitations rather than hidden defaults.

07 · Limitations

No real-world health meaning is established.

  • Labels and observations are synthetic and non-clinical.
  • The model cannot diagnose, screen, predict, treat, or triage mental-health conditions.
  • Uncalibrated tree probabilities and a fixed threshold limit how strongly abstention results can be interpreted.
  • Retained accuracy is class-distribution sensitive and should not be read without coverage and class-level metrics.
  • A temporal proxy does not establish longitudinal validity.
  • Any real extension would require consent, privacy review, governance, domain oversight, subgroup review, monitoring, and human escalation.
